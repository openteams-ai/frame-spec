# Example With Suggested Fields

This example shows a `v0.2` Frame that uses the optional metadata fields.

It includes:

- the four required fields
- suggested fields such as `version`, `scope`, `maintainer`, and `inherits`
- a concrete inheritance example

None of the suggested fields are required. They earn their place when a Frame is shared, revised, or referenced over time — `version` so consumers can tell revisions apart, `maintainer` so questions have an owner, `inherits` so broader context flows in.

Use this example when you want a more realistic starting point for shared or evolving Frames. For the opposite end, see [../code-review-norms/](../code-review-norms/), which uses only the four required fields.
