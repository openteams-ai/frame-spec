# Spec Stewardship Frame

This example shows a Frame that captures stewardship guidance for the Frame spec (currently v0.2) — the norms and decision principles for evolving the spec itself.

It is intentionally separate from the concrete mechanics described in [../../docs/spec-enhancement-process.md](../../docs/spec-enhancement-process.md).

Use this example when:

- drafting or reviewing spec enhancement proposals
- aligning contributors on how spec changes should be judged
- keeping discussion grounded in durable stewardship principles instead of implementation preferences

The key distinction is:

- the Frame captures how the project wants to think about spec evolution
- the process note captures how proposals move through the repository
