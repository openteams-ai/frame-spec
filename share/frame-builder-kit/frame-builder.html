Frame Builder

Build a valid type: frame Markdown document for non-technical users. This builder keeps the authored artifact simple while giving implementations one clear hook for detecting and handling a Frame.

Authoring Form

Fill in the required metadata first, then add as many or as few optional sections as help you capture how someone should work in this context. For list-style section fields below, use one line per item.
