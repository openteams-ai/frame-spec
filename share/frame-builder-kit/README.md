# Frame Builder Kit

This folder is meant to be easy to share as a standalone kit over chat or email.

## What To Send

You can send this whole folder as a zip, or just attach:

- `frame-builder.html`
- `sample-frame.md`

## What The Recipient Does

1. Open `frame-builder.html` in a browser.
2. Fill out the blank guided form, or click `Load Example` if they want a starting point.
3. Click `Download frame.md` or `Copy Markdown`.
4. Share or use the resulting Markdown file in their AI workflow.

## Contents

- `frame-builder.html`: the offline authoring tool
- `sample-frame.md`: a simple example of the output format

No git or local development setup is required.
